# 仕様共通記述ルール

## 1. 目的

本書は、HLDocS仕様/規約が共通仕様として成立するために、
各仕様書へ共通して記述しなければならない内容を定義する。  
本書はHLDocS仕様/規約の作成・更新時のみ参照する。  
HLDocS利用時には参照しない。

## 2. 適用範囲

本書はHLDocS仕様/規約に適用する。  
作業対象正本には適用しない。

HLDocS仕様/規約の内、以下の仕様は本書の適用対象外とする。

- HLDocSとは
- 共通仕様成立条件

## 3. 共通記述

HLDocS仕様/規約は、
共通仕様成立判定を保証するため、
以下に定義する固定文を記載しなければならない（MUST）。

```text
本仕様は、共通仕様成立状態でのみ利用できる。  
共通仕様成立状態でない場合、本仕様を根拠として判断・生成・更新・検証を行ってはならない（MUST NOT）。  
共通仕様成立状態は、「共通仕様成立条件」に従って確認する。
```

記載場所は、各仕様の先頭章の末尾とする。(MUST)
本書で定義されていない固定文を追加してはならない（MUST NOT）。
