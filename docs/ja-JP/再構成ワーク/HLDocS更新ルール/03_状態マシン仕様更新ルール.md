# 状態マシン仕様更新ルール

## 1. 目的

本書は、状態マシン仕様に定義する状態・Workflow一覧の更新条件を定義する。  
本書はHLDocS仕様/規約の作成・更新時のみ参照する。  
HLDocS利用時には参照しない。

## 2. 適用範囲

本書はHLDocS仕様/規約に適用する。  
作業対象正本には適用しない。

## 3. 更新条件

以下のいずれかを行う場合は、状態マシン仕様に定義する「3.1 状態・Workflow一覧」を更新しなければならない（MUST）。

- 状態を追加する場合
- 状態を削除する場合
- 状態を変更する場合
- Workflowを追加する場合
- Workflowを削除する場合
- Workflowを変更する場合
- Workflowの開始条件を追加・削除・変更する場合

## 4. 更新規則

更新対象

- [状態マシン仕様](../仕様/00_共通/03_状態マシン仕様.md)   
  3.1 状態・Workflow一覧

更新対象は、状態マシン仕様の「3.1 状態・Workflow一覧」とする。  
状態・Workflow一覧は、HLDocS状態マシンを構成する状態、Workflow、および開始条件と一致しなければならない（MUST）。  
状態・Workflow一覧を更新せずに、状態、Workflow、または開始条件の追加・削除・変更を行ってはならない（MUST NOT）。  
状態・Workflow一覧の更新は、状態マシン仕様と同時に行わなければならない（MUST）。
