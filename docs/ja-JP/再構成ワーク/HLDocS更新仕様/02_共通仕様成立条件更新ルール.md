# 共通仕様成立条件更新ルール

## 1. 目的

本書は、共通仕様成立条件に定義する仕様要素一覧の更新条件を定義する。  
本書はHLDocS仕様/規約の作成・更新時のみ参照する。  
HLDocS利用時には参照しない。

## 2. 適用範囲

本書はHLDocS仕様/規約に適用する。  
作業対象正本には適用しない。

## 3. 更新条件

以下のいずれかを行う場合は、共通仕様成立条件に定義する仕様要素一覧を更新しなければならない（MUST）。

- HLDocS仕様/規約を追加する場合
- HLDocS仕様/規約を削除する場合
- HLDocS仕様/規約の仕様要素を変更する場合

## 4. 更新規則

更新対象

- [共通仕様成立条件](../仕様/00_共通/02_共通仕様成立条件.md)   
  3.1 仕様要素一覧

仕様要素一覧は、HLDocS仕様/規約を構成する仕様要素と一致しなければならない（MUST）。  
仕様要素一覧を更新せずに、
HLDocS仕様/規約の追加・削除・仕様要素変更を行ってはならない（MUST NOT）。  
仕様要素一覧の更新は、共通仕様成立条件と同時に行わなければならない（MUST）。
