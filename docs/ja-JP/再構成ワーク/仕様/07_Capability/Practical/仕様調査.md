# 仕様調査

```yaml
capability: 仕様調査
type: PRACTICAL
purpose: 利用者の要求に基づいて仕様を参照し、必要な情報、構造、状態または問題を調査する
requires:
  - ファイル参照
optional: []
```

## 成立条件

requiredに指定したExecution Capability(実行能力)がすべてAVAILABLEであり、仕様調査を妨げる他の成立条件がない場合、このPractical Capability(実務能力)をAVAILABLEとしてよい（MAY）。

本Capabilityは参照・分析の実務能力を表し、調査対象を変更する能力を含まない。
