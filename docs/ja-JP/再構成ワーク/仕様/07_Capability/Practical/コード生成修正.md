# コード生成修正

```yaml
capability: コード生成修正
type: PRACTICAL
purpose: 利用者の要求に基づいてコードを新規生成または既存コードを修正する
requires:
  - ファイル参照
  - ファイル書込
optional: []
```

## 成立条件

requiredに指定したExecution Capability(実行能力)がすべてAVAILABLEであり、コード生成または修正を妨げる他の成立条件がない場合、このPractical Capability(実務能力)をAVAILABLEとしてよい（MAY）。

本CapabilityがAVAILABLEであることは、任意のファイルまたはリポジトリを無条件に変更してよいことを意味しない。
