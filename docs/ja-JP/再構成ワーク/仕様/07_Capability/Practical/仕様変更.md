# 仕様変更

```yaml
capability: 仕様変更
type: PRACTICAL
purpose: 利用者の要求に基づいて仕様を調査し、必要な変更を正本へ反映して検証する
requires:
  - ファイル参照
  - ファイル書込
optional: []
```

## 成立条件

requiredに指定したExecution Capability(実行能力)がすべてAVAILABLEであり、仕様変更を妨げる他の成立条件がない場合、このPractical Capability(実務能力)をAVAILABLEとしてよい（MAY）。

変更調査、変更対処、変更検証その他のWorkflow(ワークフロー)は本Capabilityを安全に遂行する処理規則であり、それ自体をExecution Capabilityとして重複登録してはならない（MUST NOT）。

本CapabilityがAVAILABLEであることは、任意の仕様変更が現在のRestriction Context(制限コンテキスト)で許可されることを意味しない。
