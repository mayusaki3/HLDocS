# ファイル参照

```yaml
capability: ファイル参照
type: EXECUTION
purpose: 作業対象となるファイルの内容を参照する
provided_by:
  - provider_id: repository-file-read
    provider_type: ENVIRONMENT_TOOL
    purpose: リポジトリ上のファイル内容を参照する
    match:
      required_operations:
        - repository_file_read
```

## 成立条件

現在のLLM実行環境または登録済みHLDocS Toolが、対象リポジトリのファイル内容を取得できることを確認できる場合、このExecution CapabilityをAVAILABLEとしてよい（MAY）。

ファイル一覧だけを取得できることを、ファイル内容を参照できる根拠としてはならない（MUST NOT）。
