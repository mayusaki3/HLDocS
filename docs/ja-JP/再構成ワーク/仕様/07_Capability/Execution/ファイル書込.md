# ファイル書込

```yaml
capability: ファイル書込
type: EXECUTION
purpose: 作業対象となるファイルを新規作成または更新する
provided_by:
  - provider_id: repository-file-write
    provider_type: ENVIRONMENT_TOOL
    purpose: リポジトリ上のファイルを新規作成または更新する
    match:
      required_operations:
        - repository_file_write
```

## 成立条件

現在のLLM実行環境または登録済みHLDocS Toolが、対象リポジトリのファイルを新規作成または更新できることを確認できる場合、このExecution CapabilityをAVAILABLEとしてよい（MAY）。

AVAILABLEであっても、実際の書込前にはRestriction Context(制限コンテキスト)、対象範囲および必要な承認を別途検証しなければならない（MUST）。
