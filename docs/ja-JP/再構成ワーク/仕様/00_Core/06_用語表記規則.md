# 用語表記規則

## 1. 目的

日本語版HLDocS仕様における英語機能名・実行概念を、意味を確認しやすい形で表記する。

## 2. 基本規則

利用者向け説明、仕様本文、見出しおよび表では、HLDocS固有の主要英語用語を原則として `English(日本語)` の形式で表記する。

同一節内で意味が明確な場合は、2回目以降の日本語併記を省略してよい（MAY）。

ファイル名、識別子、設定キー、列挙値、コード、パス、参照名その他の機械処理対象は変更しない（MUST NOT）。

## 4. 列挙値

列挙値は機械識別値を維持し、説明時に日本語を併記する。

例:

- `SYSTEM(システム)`
- `WORK(作業)`
- `ACTIVE(実行中)`
- `SUSPENDED(中断中)`
- `COMPLETED(完了)`
- `PENDING(未実行)`
- `SKIPPED(スキップ)`
- `UNIQUE(一意)`
- `MULTIPLE(複数)`
- `NONE(候補なし)`
- `UNKNOWN(不明)`

日本語表記を理由として、保存値または比較値そのものを変更してはならない（MUST NOT）。

## 5. 新規用語

新しいHLDocS固有英語用語を追加する場合、日本語版仕様では日本語表記も定義することを原則とする。

日本語訳は逐語訳より、HLDocS内での責務が理解しやすく、他概念と混同しにくい表現を優先する。
