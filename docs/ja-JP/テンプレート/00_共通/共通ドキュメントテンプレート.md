# 共通テンプレート

本テンプレートは、HLDocS における共通ドキュメント構造を再利用可能な形で定義するための共通テンプレートである。

適用対象は、HLDocS 形式で生成される各種ドキュメントの外枠構造であり、document_type 別本文テンプレートを差し込む共通骨格として使用する。

使用上の前提条件として、本テンプレートは HLDocS 共通仕様が成立している環境で用いなければならず、テンプレート範囲内の固定トークン・固定行・構造トークンは文字列完全一致で保持しなければならない。
