# 共通ドキュメントテンプレート

本テンプレートは、HLDocS 管理下ドキュメントに共通して適用される文書外枠を定義するためのものである。  
適用対象は、HLDocS において生成または再作成される各 document_type の文書全般である。  
使用にあたっては、本文の意味論や章構成は対象 document_type の仕様に従うこと、および本テンプレートは固定構造のみを定義し判断規則や作業手順を含まないことを前提とする。
