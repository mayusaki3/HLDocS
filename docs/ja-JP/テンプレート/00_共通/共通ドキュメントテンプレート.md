# 共通ドキュメントテンプレート

## 1. LLM-MANAGED ブロック（必須）

- 本テンプレートを基に生成されるすべてのドキュメントは、
  冒頭に **LLM-MANAGED ブロック**を配置すること。
- `doc_id` は新規生成時に必ず割り当てる。
- 本ブロックは **LLM のみが編集する**。

## 2. 基本構造（必須）

以下の構造を厳守すること。

1. LLM-MANAGED ブロック  
2. 空行  
3. 階層リンク行  
4. 空行  
5. 本文  
6. 空行  
7. `---`  
8. 空行  
9. 階層リンク行（再掲）

## 3. 階層リンク行

- ドキュメントの論理階層を `>` 区切りで記述する。
- 先頭と末尾で同一内容を記載する。

## 4. 本文記述ルール

- Markdown を使用する。
- 見出しレベル・箇条書きは意味構造を反映する。
- 表現の可読性より **構造の一貫性**を優先する。
