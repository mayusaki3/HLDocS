# 共通ドキュメントテンプレート

本書は、HLDocS における **すべての document_type に共通する外枠構造**を定義する。  
本文の具体内容・章構成・記述粒度は、document_type 別テンプレートおよび生成プロンプトによって決定される。

本テンプレートは、以下を満たすことを目的とする。

- document_type 非依存であること
- LLM-MANAGED ブロックを唯一のメタデータ定義位置とすること
- Transport Encoding による提示・回収と独立して成立すること
- 差し替え・再生成時に構造的一貫性を保てること
