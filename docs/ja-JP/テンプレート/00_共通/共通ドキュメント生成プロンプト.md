# 共通ドキュメント生成プロンプト

## 指示

以下の条件を満たす Markdown ドキュメントを生成せよ。

### 必須条件

- HLDocS 共通ドキュメント構造に従うこと
- LLM-MANAGED ブロックを先頭に配置すること
- `doc_id` は新規生成すること
- `canonical_document` と `transport` を必ず指定すること
- 人間が編集すべき箇所と LLM 管理領域を混在させないこと

### 禁止事項

- output_mode を使用しない
- HL-FENCE を独立仕様として復活させない
- transport によって意味や構造を変更しない
