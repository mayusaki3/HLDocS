# document_type:index テンプレート

## 本文構造（index 固有）

### （任意）ガイド文

- ユーザー指示がある場合のみ記載する
- 全体目的・使い方レベルに限定する
- 個別ドキュメントの説明・要約を含めない
- 判断規則・運用規約・生成方法を含めない
- 指示がない場合、このセクション自体を出力しない

### リンク一覧

- 見出しは **分類・階層**の表現にのみ使用する
- 各項目は **リンクのみ**で構成する
- 説明文・補足文は記載しない
