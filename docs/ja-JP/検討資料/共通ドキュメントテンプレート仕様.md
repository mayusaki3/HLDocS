# HLDocS 共通ドキュメントテンプレート仕様（初版・検討・改訂）

本書は、HLDocS における  
**共通ドキュメントテンプレートの構造・命名・翻訳規約**を定義する。

本仕様は検討段階にあり、正規仕様ではない。

---

## 1. 目的

- 人間と LLM が同一フォーマットでドキュメントを扱う
- 正規構造・同一性を LLM が保証する
- 人間は意味理解と判断に集中する
- ファイル名・翻訳差異による破綻を防ぐ

---

## 2. 基本構造

共通ドキュメントは、以下の構造を持つ。

1. LLM 管理下ブロック（先頭）
2. 人間向け階層リンク行（先頭）
3. ドキュメントタイトル
4. 本文（Human 編集領域）
5. 区切り線
6. 人間向け階層リンク行（末尾）

---

## 3. LLM 管理下ブロック

- HTML コメントとして記述する
- 人間は原則編集しない
- LLM が生成・更新する
- **Canonical 情報**として扱う

代表的な項目：

- doc_id（唯一の同一性）
- lang（文書言語）
- canonical_title（当該言語でのタイトル）
- source_of_truth（原語）
- translation_of（派生元 doc_id）
- output_mode（canonical-md / ui-copy）
- transport（none / ui-copy）

---

## 4. ドキュメントタイトルの規約

### 4.1 役割
- タイトルは **意味・概念の名前**
- 人間の理解を最優先とする

### 4.2 使用可能文字
- 日本語（漢字・かな）
- 英語
- 全角記号（・、（）等）
- スペース

ファイルシステム制約は **一切考慮しない**。

### 4.3 正規性
- タイトル行（# タイトル）は Canonical
- 翻訳により内容が変わってよい
- 同一性は doc_id により保証する

---

## 5. ファイル名の規約（原語版）

### 5.1 役割
- ファイル名は **配置・参照用の識別子**
- 意味・同一性を担わない

### 5.2 使用可能文字
- 日本語
- 英数字
- _（アンダースコア）
- -（ハイフン）

禁止：
- OS 依存で問題になる記号
- 全角スペース
- 絵文字

### 5.3 番号付き形式
- 配置・順序用として番号を付与する
- 意味は持たせない

形式（例）：
NN_タイトル.md

例：
02_人間とLLMの役割分担.md

---

## 6. タイトルとファイル名の関係

- タイトルとファイル名の完全一致は要求しない
- 記号差・表現差を許容する
- タイトルをファイル名制約に合わせて劣化させてはならない

---

## 7. 翻訳ドキュメントの規約

### 7.1 基本原則
- 原語版のみが Source of Truth
- 翻訳版は派生物
- doc_id は全言語で共通

---

### 7.2 翻訳後のタイトル
- 自然な翻訳を優先する
- 原語タイトルとの文字的一致は不要

---

### 7.3 翻訳後のファイル名（重要）

- 翻訳語ベースのファイル名を使用する
- 番号（NN_）は全言語で共通

例：
docs/ja-JP/02_人間とLLMの役割分担.md  
docs/en-US/02_Roles_of_Humans_and_LLMs.md

翻訳後ファイル名は、原則として：

- 英数字
- アンダースコア
- snake_case または PascalCase

---

## 8. Human 編集領域の扱い

- 人間が編集してもよい
- ただし **整合性回復責務は LLM にある**
- 本文は Non-Canonical として扱う

---

## 9. 出力モードと Transport Encoding

### canonical-md
- 正規成果物
- エスケープなし Markdown
- API / UIファイル / CLI 等を含む

### ui-copy
- Transport Encoding を施した搬送表現
- ^^^ → コードフェンスの代替
- 保存後に復元が必要
- 復元後の内容が正規成果物

---

## 10. 正規化方針

- 本仕様確定後：
  - docs/ja-JP/テンプレート/ に移動
  - HLDocS 正規仕様として再発行する
