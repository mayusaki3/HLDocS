# 生成時の問い合わせ必須ルール（document_type / テンプレート未合意）

本規約は、人間からの指示に基づいて HLDocS 管理下ドキュメントを生成する際に、
document_type およびテンプレート選択が未合意の場合の振る舞いを定義する。

---

## 1. 適用範囲（MUST）

- 人間の自然言語指示からドキュメントを生成する全ケースに適用する。
- 合成ツール経由・手動合成経由のいずれにも適用する。

---

## 2. 生成前提（MUST）

ドキュメント生成を開始するために、以下が確定していなければならない。

- document_type
- 使用テンプレート（template_role / spec_template 等の選択結果）

---

## 3. 問い合わせ必須（MUST）

以下のいずれかが未確定の場合、LLM は **生成してはならない**。
代わりに、必要最小限の確認質問を返さなければならない。

- document_type が未確定
- document_type は確定しているが、適用すべきテンプレートが未確定
- 指示が「新規作成」か「既存文書の更新」か未確定
- 既存文書の更新であるにもかかわらず、対象ファイル（doc_id相当）が未確定

---

## 4. 問い合わせの最小化（MUST）

問い合わせは、次の方針で最小化する。

- 1ターンで必要な確認をまとめて行う（最大3点まで）
- 選択肢は ENUM から提示する（例：spec/index/template/prompt/note）
- テンプレートは「役割名（template_role）」で提示する（例：spec.general / spec.document_type）

---

## 5. 合成ツール側の要件（MUST）

合成ツールは以下を満たさなければならない。

- 未合意のまま合成・生成を実行しない（fail-fast）
- 未合意項目を明示して終了する（終了コード=1）
- trace に「未合意で中断した」ことを残す

---

## 6. 例外（MAY）

以下の場合に限り、問い合わせを省略してよい。

- ユーザーが document_type とテンプレート役割を明示指定している
- 既存文書の更新で、対象ファイルが明示されている（doc_idが確定）
