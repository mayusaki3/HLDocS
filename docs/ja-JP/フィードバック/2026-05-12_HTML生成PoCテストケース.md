# HTML生成PoCテストケース

## 1. 位置付け

本書は、HLDocS 自身を対象とした HTML 生成 PoC-1 の実装前テストケースを記録する。

本書は正規仕様ではなく、PoC 実装・検証に向けたフィードバック文書として扱う。

---

## 2. テスト対象

対象は、HLDocS 自身の Markdown 正本文書群を入力とした HTML 生成 PoC とする。

対象 profile は以下とする。

- overview
- reference

以下は PoC-1 の対象外とする。

- test-report
- 実テスト結果
- evidence
- coverage dashboard
- 完全な Traceability 可視化

---

## 3. 前提条件

PoC 実装は、以下の制約を満たすこと。

- Markdown 正本を canonical とする
- HTML は read-only Operational Representation とする
- HTML から Markdown を逆生成しない
- Manifest に存在しないページへリンクしない
- 未生成ページは `not generated` として扱える
- ファイル名・ディレクトリ名に空白文字を含めない
- 物理ファイル名・物理パス・並び順制御番号を人間向けリンク表示名として使用しない

---

## 4. テストケース一覧

### HTML-POC-TC-001: index.html 生成

目的：HTML ドキュメント全体の入口が生成されることを確認する。

入力：

```text
docs/ja-JP
```

期待結果：

```text
docs/ja-JP/HTMLドキュメント/index.html
```

が生成されること。

判定：PASS / FAIL

---

### HTML-POC-TC-002: overview/index.html 生成

目的：overview profile の入口が生成されることを確認する。

期待結果：

```text
docs/ja-JP/HTMLドキュメント/overview/index.html
```

が生成されること。

判定：PASS / FAIL

---

### HTML-POC-TC-003: reference HTML 生成

目的：Markdown 正本文書から reference HTML が生成されることを確認する。

期待結果：

```text
docs/ja-JP/HTMLドキュメント/reference/*.html
```

が 1 件以上生成されること。

判定：PASS / FAIL

---

### HTML-POC-TC-004: HTML Site Manifest 生成

目的：HTML Site Manifest が生成されることを確認する。

期待結果：

```text
docs/ja-JP/HTMLドキュメント/manifest/site-manifest.json
```

が生成されること。

判定：PASS / FAIL

---

### HTML-POC-TC-005: Manifest 必須項目

目的：Manifest の各 page entry に最低限の項目が含まれることを確認する。

期待項目：

- page_id
- profile
- source_markdown
- canonical_title
- doc_id
- sec_id
- output_html_path
- source_hash
- stale
- link_targets

判定：PASS / FAIL

---

### HTML-POC-TC-006: Markdown 正本リンク

目的：reference HTML から元 Markdown 正本へ遷移できることを確認する。

期待結果：

- source markdown へのリンクが存在する
- リンク表示名に物理ファイル名を使用しない
- リンク表示名に並び順制御番号を使用しない

判定：PASS / FAIL

---

### HTML-POC-TC-007: Manifest ベースリンク

目的：HTML ドキュメント間リンクが Manifest に基づくことを確認する。

期待結果：

- HTML 内部リンク先が Manifest の page entry に存在する
- Manifest に存在しないページへのリンクが存在しない

判定：PASS / FAIL

---

### HTML-POC-TC-008: not generated 表示

目的：PoC-1 対象外の profile が未生成として扱われることを確認する。

期待結果：

- test-report が未生成であることを表示できる
- 未生成ページへのリンクを生成しない

判定：PASS / FAIL

---

### HTML-POC-TC-009: stale 初期状態

目的：初回生成時の stale 状態を確認する。

期待結果：

- 初回生成された page entry の `stale` が `false` である
- `source_hash` が Manifest に記録される

判定：PASS / FAIL

---

### HTML-POC-TC-010: 空白ファイル名禁止

目的：HTML generated artifact に空白入りファイル名が生成されないことを確認する。

期待結果：

```bash
find docs/ja-JP/HTMLドキュメント -name "* *"
```

が空であること。

判定：PASS / FAIL

---

### HTML-POC-TC-011: LLM-MANAGED metadata 抽出

目的：Markdown 正本の LLM-MANAGED ブロックから metadata を抽出できることを確認する。

期待結果：

- doc_id を抽出できる
- canonical_title を抽出できる
- document_type を抽出できる
- canonical_document を抽出できる

判定：PASS / FAIL

---

### HTML-POC-TC-012: sec_id 推測禁止

目的：存在しない sec_id を推測生成しないことを確認する。

期待結果：

- source Markdown に sec_id が存在しない場合、Manifest の sec_id は空配列または未設定扱いとなる
- generator が sec_id を自動推測しない

判定：PASS / FAIL

---

### HTML-POC-TC-013: profile 指定

目的：profile 指定が反映されることを確認する。

入力例：

```bash
python tools/html_generator/generate_html.py \
  --input docs/ja-JP \
  --output docs/ja-JP/HTMLドキュメント \
  --profile overview,reference
```

期待結果：

- overview が生成される
- reference が生成される
- test-report は生成されない

判定：PASS / FAIL

---

### HTML-POC-TC-014: 再生成

目的：HTML generated artifact を再生成できることを確認する。

期待結果：

- 再実行しても Manifest が破綻しない
- 既存 HTML が更新される
- source_hash が更新される

判定：PASS / FAIL

---

### HTML-POC-TC-015: PoC-1 対象外明示

目的：PoC-1 で対象外の内容が推測生成されないことを確認する。

期待結果：

- 実テスト結果を推測生成しない
- evidence を推測生成しない
- coverage dashboard を推測生成しない
- test-report ページを推測生成しない

判定：PASS / FAIL

---

## 5. 完了条件

PoC-1 は、少なくとも以下を満たした場合に完了候補とする。

- HTML-POC-TC-001 〜 HTML-POC-TC-015 がすべて PASS
- FAIL がある場合、原因と対応方針がフィードバックへ記録されている
- 仕様へ反映すべき項目が整理されている

---

## 6. 後続

PoC-1 完了後、検証結果をフィードバックへ集約し、必要な内容を HTML 系仕様へ一括反映する。
