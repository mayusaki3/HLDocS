# HLDocS フィードバック整理（共通・運用補足）

本ドキュメントは、HLDocS 共通ではあるが  
**仕様本文に直接書かず、設計指針・補足として扱う事項**を整理する。

---

## 1. 可読性の担保方法

- doc_id に可読性は求めない
- 可読性は以下で担保する
  - ファイル名
  - ドキュメントタイトル
  - 章構成
- 必要に応じて補助フィールドを設けることは可能

---

## 2. 目次.md の扱い

- 目次.md はナビゲーション専用文書
- HLDocS 管理対象外として運用しても問題ない
- LLM-MANAGED / last_verified 等の必須化は行わない

---

## 3. Canonical と doc_id の関係

- doc_id を持つことと Canonical であることは別概念
- 非 Canonical 文書でも doc_id を持つことがある

---

HLDocS 仕様・テンプレートへ直接は反映しない。
