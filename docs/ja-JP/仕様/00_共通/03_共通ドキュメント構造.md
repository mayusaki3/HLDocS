# 共通ドキュメント構造

本書は、HLDocS における **document_type 非依存の共通ドキュメント構造**を定義する。

---

## 1. 基本方針

- 本仕様はすべての document_type に共通して適用される
- document_type 固有の責務・構造は別仕様で定義する
- ファイル名・ディレクトリ構成・番号は意味を持たない

## 2. 基本構造（MUST）

すべての HLDocS 管理下ドキュメントは、以下の構造を持つ。

1. LLM-MANAGED ブロック
2. 空行
3. 階層リンク行
4. 空行
5. 本文
6. 空行
7. `---`
8. 空行
9. 階層リンク行（再掲）

## 3. LLM-MANAGED ブロック（MUST）

- 本ブロックはドキュメント先頭に配置する
- 本ブロック内の内容は **LLM のみが編集することを前提とする**
- 人間による直接編集は破壊的変更とみなされる
- 本ブロックの仕様は [LLM-MANAGEDブロック規約](./03_LLM-MANAGEDブロック規約.md) を参照。

## 4. 階層リンク行（MUST）

- ドキュメントの論理階層を `>` で表現する
- 末尾にも同一の階層リンク行を再掲する

## 5. ドキュメント並べ替え番号規定（MUST）

- ファイル名およびフォルダ名は、
  ファイルシステム上の並び順を制御する目的に限り、
  自由に先頭に番号を付与してよい  
  （番号付与以外は変更してはならない）
- 番号は **NN_ 形式**とする
  - N の桁数は自由である
  - 末尾は必ず `_` で終わる
- 番号は意味・役割・仕様上の区別を持たない
