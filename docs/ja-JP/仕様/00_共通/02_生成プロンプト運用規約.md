# 生成プロンプト運用規約

本書は、HLDocS において **生成プロンプトおよびテンプレートを設計・生成する際の前提となる想定利用形**を定義する。  
本規約は、HLDocS の仕様・構造・document_type 間の関係性・意味論そのものを定義するものではない。

本書の目的は、  
**以降で定義される各仕様からテンプレート／生成プロンプトを作成する際に、  
「実運用でどのように使われることを想定しているか」だけを共有すること**にある。

---

## 1. 本書の位置づけ

- 本書は **HLDocS の概念仕様・関係性・役割定義を再定義しない**
- 本書は **利用者向けの操作手順書ではない**
- 本書は、以下を作成する際の **設計前提を共有する文書**である
  - 共通テンプレート
  - document_type 別テンプレート
  - 共通生成プロンプト
  - document_type 別生成プロンプト

本書は、  
**HLDocS が提供するテンプレート／生成プロンプトが、  
実運用においてどのように利用されることを想定して設計されるか**  
のみを扱う。

---

## 2. 想定する利用モデル（前提）

HLDocS では、生成フェーズにおいて以下の利用モデルを想定する。

- LLM に与えられる入力は：
  - 共通テンプレート／共通生成プロンプト
  - 生成対象 document_type のテンプレート／生成プロンプト
- 生成時に、仕様本文・規約本文・説明文書を  
  LLM に与えることを前提としない
- 生成プロンプトは、  
  **テンプレートが与えられている状況を前提として設計される**

この前提に基づき、  
テンプレートおよび生成プロンプトは  
**入力がテンプレート／生成プロンプトに限定される状況でも  
正しく機能すること**を想定して設計される。

---

## 3. テンプレート設計時の前提

以降で定義されるテンプレートは、以下の前提で設計される。

- **共通テンプレート**
  - 文書全体の構造を定義する
  - LLM-MANAGED ブロック、階層リンク、ヘッダ／フッタ等を含む
- **document_type 別テンプレート**
  - 本文構造のみを定義する
  - 共通テンプレートの構造・要素を再定義しない

生成プロンプトは、  
**これらのテンプレートがすでに確定した構造として存在すること**  
を前提に設計される。

---

## 4. 生成プロンプト設計時の前提

生成プロンプトは、以下を前提として設計される。

- 生成プロンプトは：
  - テンプレートの適用条件
  - 判断ルール
  - 作業手順
  を指示するためのものである
- 内容仕様・document_type の役割関係・正当性は  
  生成プロンプトの責務ではない
- 生成プロンプトは、  
  テンプレートや仕様を再解釈・補完する役割を持たない

生成プロンプトは、  
**テンプレートで確定した構造の中で、  
必要最小限の判断のみを LLM に委ねる**  
ことを目的として設計される。

---

## 5. 設計上の非機能前提

テンプレートおよび生成プロンプトは、以下の非機能前提を満たすことを想定して設計される。

- LLM は会話履歴の保持を前提としてはならない
- 生成結果は単体で完結し、再現可能でなければならない
- 生成は、過去の生成結果や状態に依存してはならない

これらは、  
**生成プロンプトおよびテンプレート設計時の前提条件**であり、  
生成時の操作手順や実行方法を規定するものではない。

---

## 6. 対象外とする領域

本書が定義する設計前提には、以下を含まない。

- 提示・回収方法
- 実行環境（ChatGPT UI / API 等）に依存する振る舞い
- 出力形式の変換や UI 崩壊対策
- 運用レイヤにおける制御属性

これらは、  
[Transport Encoding 規約](./05_Transport_Encoding規約.md) や利用環境側の設計に委ねられる。

---

## 7. LLM-MANAGED ブロックに関する設計前提

- LLM-MANAGED ブロックは **成果物メタデータ**として扱われる
- 生成プロンプトは、  
  LLM が決定すべきでないメタデータ領域を侵害しない前提で設計される
- 提示・回収・実行環境に属する属性は、  
  生成プロンプトおよびテンプレートの設計対象外とする

具体的なキー定義や制約は、  
[LLM-MANAGED ブロック規約](./04_LLM-MANAGEDブロック規約.md) に委ねる。

---

## 8. 内部自己検査（非出力・MUST）

テンプレート／生成プロンプトは、以下を満たすことを前提に設計される。

- 入力がテンプレート／生成プロンプトで完結していること
- テンプレート構造（共通／document_type 別）に依存した設計になっていること
- 対象外領域（提示・回収・実行環境）を判断対象に含めていないこと

これらを満たさない設計は、  
HLDocS の想定利用形から逸脱しているとみなす。
