# ChatGPT UIでの使い方

本書は、HLDocS に基づくドキュメント生成・再作成を  
**ChatGPT の UI 上で人間が安定して操作するための実用ガイド**である。

テンプレートや生成プロンプトそのものの仕様ではなく、  
**どのファイルを、どの順で添付し、どのような指示を書くか**に焦点を当てる。

---

## 1. この文書の考え方（人間向け）

- 本書は **人間の操作ミスを減らすための運用ノート**である
- 正解の構文よりも「迷わず操作できること」を優先する
- 仕様（spec）や規約に書ききれない判断基準をここに集約する
- **note は原則として再生成しない**
  - 修正は人間が直接行い、差し替える

---

## 2. document_type をどう選ぶか（最初に確認）

指示を書く前に、**何を作りたいのか**を明確にする。

- spec  
  要件・振る舞い・I/F を確定させる成果物
- testspec  
  spec を検証するための観点・期待結果
- usage  
  利用者向けの操作手順・使い方説明
- minutes  
  議論・検討・意思決定の記録（後から spec を起こす元情報）
- note  
  方針・運用知見・補足説明（迷ったらまず note）
- index  
  目次・リンク集
- template / prompt  
  LLM に渡すための雛形・生成指示（成果物ではない）

---

## 3. 推奨される基本フロー（最重要）

### 手順 1：新しいチャットを開始する

原則として **1 文書 = 1 チャット**。

以下のような挙動が出たら、  
同じチャットを続けるより **新しいチャットへ移動することを推奨**する。

- 指示していない document_type になる
- transport 指定を無視する
- 再作成なのに doc_id を変更する
- 「ui_copy ではできない」等を理由に内容を省略する
- 説明文だけを返し始める

---

### 手順 2：ケース別「添付セット＋指示文」

以下は **実際にそのまま使える完成形**。  
ファイルを添付してから、指示文を貼り付ける。

---

#### A. 新規作成（note など単独文書）

対象：
- note
- index
- template
- prompt  
※ spec / testspec / usage とは切り分ける

**添付するもの**

- 共通ドキュメントテンプレート（必須）
- 共通ドキュメント生成プロンプト（必須）
- 対象 document_type のテンプレート
- 対象 document_type の生成プロンプト

**指示文（編集前提の雛形）**

```
添付したテンプレートおよび生成プロンプトに従い、以下の指示を実行すること。
- 新規作成として作成する
- transport は ui_copy
- document_type は note（ここに作成したい document_type を指定）

（ここに作成したい内容・背景・目的を記載する）
例：
これからプロンプト合成ツールの要件を検討する。
検討時の判断基準や注意点を note として整理する。
```

---

#### B. 再作成（既存 spec 単独）

**添付するもの**

- 既存 spec（必須）
- 共通ドキュメントテンプレート
- 共通ドキュメント生成プロンプト
- spec テンプレート
- spec 生成プロンプト

**指示文**

```
添付したテンプレートおよび生成プロンプトに従い、以下の指示を実行すること。
- 添付した既存ファイルを正として再作成する
- doc_id は変更しない
- transport は ui_copy
- document_type は spec

（再作成理由・修正方針があればここに記載）
```

---

#### C. minutes を基に spec を作成する場合

**添付するもの**

- minutes
- （存在する場合）既存 spec
- 共通ドキュメントテンプレート
- 共通ドキュメント生成プロンプト
- spec テンプレート
- spec 生成プロンプト

**指示文**

```
添付したテンプレートおよび生成プロンプトに従い、以下の指示を実行すること。
- 添付した minutes の該当章を基に spec を作成する
- 元の minutes は変更しない
- transport は ui_copy
- document_type は spec
```

---

## 4. transport について（参考）

- ChatGPT UI では **ui_copy を前提**
- download はファイル取得が必要な場合のみ
- true_out は API 利用時の値であり、UI 操作では使用しない
