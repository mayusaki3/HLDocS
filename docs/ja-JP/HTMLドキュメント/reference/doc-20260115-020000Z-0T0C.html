HLDocS ドキュメント目次

HLDocS の目的

• 人間と LLM が同一フォーマットでドキュメントを扱う

• 正規構造・同一性を LLM が保証する

• 人間は意味理解と判断に集中する

• UI 上での回収失敗（セッション切れ等）による再生成を減らす
